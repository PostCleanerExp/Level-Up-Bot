LEVELUP VERIFICATION DESTINATION PAGE

Deploy these files to GitHub Pages or another static host, then use the published index.html URL as the destination when creating your VPLink shortlink.

IMPORTANT: This ZIP is only the destination-page UI / front-end preview. The displayed LvlUp code is generated in the browser and is NOT a secure authorization code. Do not connect it to production access until server-side code issuance, VPLink completion proof (if available), one-time redemption, and expiry validation are implemented in the LevelUpBot backend.
